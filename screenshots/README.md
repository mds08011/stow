# Screenshots

Drop the captures below into this folder using these exact filenames — the table in the
root `README.md` already links to them, so the images appear as soon as the files exist.

Take them on a real device (a Pixel is the reference), portrait, with the system theme
you want to show off. Crop out the status bar clock if it shows anything personal.

| File | What to capture |
|---|---|
| `main.png` | Main screen: large **Start Recording** button, mic indicator (Internal / Bluetooth), chronometer, daily usage line, the polish preset button in the bottom row, version label, toolbar icons |
| `result.png` | Editable result after a run: the **Result — polished (editable)** label, the **Show raw** toggle, transcript text, **Copy**, and **Start Recording** at the top |
| `notification.png` | Shade while recording — "Stow — Recording in progress..." with **Pause** and **Stop Recording**. A second shot of **Transcription ready** is a bonus |
| `jargon.png` | Custom Vocabulary / Jargon dialog with a few real terms |
| `history.png` | Searchable history list with timestamps, durations, and the "polished" badge |
| `detail.png` | Note detail with Copy / More actions |
| `presets.png` | Polish presets manager showing Clean prose and Task capture |
| `tile.png` | Quick Settings shade with the Stow tile active |

Once the files are in place, the placeholder note in the root README's Screenshots
section can be deleted.
